
# Rota Ásia

## Sobre o projeto

Rota Ásia é um guia turístico digital desenvolvido
para apresentar cinco destinos turísticos do continente
asiático.

## Objetivo

Facilitar a descoberta de destinos turísticos,
apresentando informações relevantes sobre paisagens,
cultura e atrações.

## Destinos selecionados

1. Bali - Indonésia
2. Baía de Ha Long - Vietnã
3. Kyoto - Japão
4. Ilha de Jeju - Coreia do Sul
5. Chiang Mai - Tailândia

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
