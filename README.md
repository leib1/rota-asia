
# Rota Ásia

## Sobre o projeto

Rota Ásia é um guia turístico digital desenvolvido
para apresentar cinco destinos únicos no continente asiático.

## Objetivo

Facilitar a descoberta de destinos turísticos,
apresentando informações relevantes sobre paisagens,
cultura, atrações e experiências.

## Destinos selecionados

1. Bali - Indonésia
2. Baía de Ha Long - Vietnã
3. Kyoto - Japão
4. Ilha de Jeju - Coreia do Sul
5. Zhangjiajie - China

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## Estrutura atual

- index.html: página inicial
- css/style.css: estilos da página
- assets/images/: recursos visuais
