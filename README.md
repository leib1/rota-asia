# Tourásia

## Sobre o projeto

Tourásia é um guia turístico digital desenvolvido para apresentar cinco destinos turísticos do continente asiático. O projeto reúne informações sobre paisagens, cultura, geografia, atrações e características de cada localidade, oferecendo uma experiência de navegação intuitiva e acessível.

## Objetivo

Facilitar a descoberta de destinos turísticos asiáticos por meio de um portal informativo, permitindo que os visitantes conheçam diferentes regiões, suas características culturais e naturais e seus principais pontos de interesse.

## Destinos selecionados

1. **Bali — Indonésia**
2. **Baía de Ha Long — Vietnã**
3. **Kyoto — Japão**
4. **Ilha de Jeju — Coreia do Sul**
5. **Zhangjiajie — China**

## Funcionalidades

- Apresentação dos cinco destinos turísticos.
- Catálogo visual com imagens e descrições.
- Pesquisa por nome do destino, país ou atração.
- Filtros por categorias turísticas.
- Páginas individuais com informações detalhadas sobre cada destino.
- Navegação entre as páginas dos destinos.
- Alternância entre tema claro e escuro.
- Layout responsivo para diferentes tamanhos de tela.

## Tecnologias utilizadas

- **HTML5:** estruturação das páginas.
- **CSS3:** estilização, identidade visual, responsividade e temas.
- **JavaScript:** implementação da pesquisa, dos filtros e da alternância de temas.
- **Git:** controle de versão.
- **GitHub:** hospedagem do repositório e gerenciamento do código-fonte.

## Como executar o projeto

1. Clone o repositório:
   ```bash
   git clone https://github.com/leib1/rota-asia.git
   ```

2. Acesse a pasta do projeto:
   ```bash
   cd rota-asia
   ```

3. Abra o arquivo `index.html` em um navegador ou utilize a extensão **Live Server** no Visual Studio Code para executar o projeto localmente.
